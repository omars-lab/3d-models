# 3D Model Gallery - Islamic Cookie Cutters

A beautiful collection of Islamic-inspired 3D cookie cutters designed with OpenSCAD. This repository contains both the source code and rendered 3D models for traditional Middle Eastern and Islamic geometric designs.

## 🌟 Live Gallery

**👉 [View the Interactive Gallery](https://3d-models.bytesofpurpose.com/)**

Experience the full interactive gallery with detailed descriptions, source code links, and 3D model previews.

## 🎨 Featured Designs

### Geometric Patterns
- **Arabesque** - Intricate eight-fold symmetry with outer stars and complex arabesque designs
- **Eight Point Star** - Beautiful geometric star with traditional Islamic art inspiration
- **Circle** - Simple yet elegant circular design

### Islamic Symbols
- **Crescent with Star** - Classic Islamic symbol perfect for Eid celebrations
- **Minaret** - Architectural tower representing Islamic mosques

### Architectural Elements
- **Mosque 1 & 2** - Traditional Islamic architecture with dome and minaret elements
- **Lantern Series** - Three variations of Middle Eastern lantern designs with unique geometric patterns

## 🛠️ Technical Details

### Source Files
- **OpenSCAD** (`.scad`) files in `src/CookieCutters/`
- **STL files** for 3D printing in `build/stls/`
- **Rendered images** in `build/images/`

### Dependencies
- OpenSCAD for 3D modeling
- Basic shapes and complex shapes modules (included in `src/`)

## 🖨️ 3D Printing

All models are ready for 3D printing:
- STL files are optimized for cookie cutter use
- Recommended layer height: 0.2mm
- Infill: 20-30%
- Supports: Generally not required

## 📁 Project Structure

```
3d-models/
├── src/
│   ├── CookieCutters/          # OpenSCAD source files
│   ├── BasicShapes.scad        # Basic geometric shapes
│   └── ComplexShapes.scad      # Complex geometric patterns
├── build/
│   ├── images/                 # Rendered model images
│   └── stls/                   # 3D printable STL files
├── index.html                  # Interactive gallery
├── data.js                     # Model metadata
└── README.md                   # This file
```

## 🎯 Usage

### Viewing the Gallery
1. Open `index.html` in your browser
2. Browse the interactive gallery
3. Click "View Code" to see OpenSCAD source
4. Click "Download STL" to get 3D printable files

### Modifying Designs
1. Open the corresponding `.scad` file in OpenSCAD
2. Modify parameters as needed
3. Render and export as STL for 3D printing
