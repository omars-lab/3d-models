Size

A shortcut for the size knob — mini (40 mm) and standard (90 mm) set the same param the slider does.

Knobs

Relief shape

Band is a flat-topped strap; rods makes each strap a half-round rod, so lines read as equal cylinders and junctions round off. Same footprint, width and height — only the top profile changes, and every structural check is shared.

Colors

Each region prints in its own filament. Color is a preview and an AMS map — print correctness is per-body geometry, not the render color.

Orbits

An orbit is one shape turned about the pattern's centre, numbered outwards — the same numbers bikar bands prints. A ticked orbit is filled solid.

Or click a piece in the picture to pick its ring.

Piece colors

Seen from above, finishes drawn roughly: silk and metal with a sheen, sparkle with flecks, translucent see-through. Point at a row to light its pieces; click a piece to pick its row.

    Structural checks

    Every coaster validator the script's coaster block reaches (CV1–CV7 for a solid slab, CV8–CV9 for an interlocked one, CV10 for a minimal one), live. A coaster that fails one describes a part that will not print, so a failure blocks the mesh rather than showing here as a warning.

        One construction, every join it ships: each picture is two 80 mm coasters mated edge to
        edge, as the engine builds them, with the seam enlarged on the right. The ruler there marks
