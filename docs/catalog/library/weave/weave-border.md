## What the file says

```text
Weave-Border: Braided Border Strip
Technique: linear strapwork on rectangular tile
Reference: Book p.58 "Braided Borders" — gilded interlaced
  borders framing geometric panels in Islamic book arts
Construction:
  1. Circle C0 divided into 8 creates the base motif
  2. connect every 2 gives the 8-pointed star crossings
  3. strapwork renders as interlaced bands
  4. Single motif with no tiling — demonstrates the unit cell
Key insight: braided borders are 1D repeat patterns.
  A full border would tile this horizontally with tile rectangular.
```
