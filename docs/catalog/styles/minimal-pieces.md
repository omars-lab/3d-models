# The minimal-pieces coaster style

Every hole of the ten-fold minimal coaster filled back in as a loose piece, one color per ring, set in a strap frame — the coaster to color piece by piece.

Not in the [coaster styles table](../../../.claude/skills/import-construction/coaster-styles.md) yet: only one pattern is made this way.
