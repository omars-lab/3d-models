# The minimal-tab coaster style

Minimal-frame with a tab grown from every other edge and a notch through the frame on the edges between, so neighbours join tab to notch with no third piece. Hexagon only.

The name, the file it comes from and where it was decided are in the [coaster styles table](../../../.claude/skills/import-construction/coaster-styles.md).
