Omar turned down a 3-question AskUserQuestion round for the after-print judging. He asked for a hub page instead: "where I can see each peiece individually, and what peices im supposed to compare, what I am to compare". He approved the mockup (2026-10-22): each piece is a tile labeled with the id cut into it, "pick up these" beside "against these" (an earlier print's photos), then Do and Look for, one button per answer, "not judged yet", and a note box.

He picked "On the plate page": answers and notes are written word for word into the plate page's After-the-print table. A session then turns them into the print record with review-print, so the logic that maps a row to per-piece verdicts stays in one place.

**Why:** a text question gives no picture and no piece ids, so he can't judge from it. Two writers of the record would be two code paths that can disagree.

**How to apply:** don't ask the after-print rows in chat. Point him to the hub page, and read the answers back from the plate page. Related: [[after-print-questions-as-sop]], [[questions-name-carved-ids]], [[decisions-as-vault-page]].
