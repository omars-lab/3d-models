Omar 2026-10-08: "i want the questions to reference the piece ids". He said it when pkt-1's
after-print questions used the page's bed names (P2a, P4a) and pair letters (O–R), which are not
what he sees in his hand.

**Why:** the carved id (D-109, D-114) is the only name printed on the piece. A question that uses
any other name makes him go to the page and work out which piece is which.

**How to apply:** in every after-print question, name the piece by its carved id, as the page's id
picture shows it. pkt-1's lowers read 4S (P2a, whose O reads as a zero), 4P, 4Q and 4R. Uppers carry
no id, only the pair letter on the cut face, so name them as "the upper that pairs with 4Q". Read the
ids from the page's id section (`<plate>-media/ids.png`) before asking. Related: [[try-joins-in-print]].
