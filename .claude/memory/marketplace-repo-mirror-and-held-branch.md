**`~/Workspace/git/oeid-claude-plugin-marketplace` has NO PR flow.** Two remotes: `origin` = `mac-studio:git/...` (the real internal upstream, often offline) and `github` = `omars-lab/claude-plugin-marketplace` (a PUBLIC one-way mirror). The mirror is fed ONLY by `make sync-remote` (`scripts/sync-to-github.sh`), which rewrites commit metadata and pushes via an internal `__github_sync` branch. A `.githooks/pre-push` guard **blocks direct branch pushes to `github`** (message points at `make sync-remote`; bypass only with `--no-verify`). This is why local `main` and `github/main` show as **332 ahead / 332 behind with byte-identical trees** — same content, rewritten hashes. So a "GitHub PR" is not how this repo works; landing = commit to internal `main` → `push origin main` → `make sync-remote`. `make validate` / `validate-plugin PLUGIN=<name>` check plugin structure; pre-commit runs gitleaks.
