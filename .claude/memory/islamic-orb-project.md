Omar builds 3D-printable Islamic geometric orbs (star-lattice spheres, STL) plus pieces, walls, LEGO-compatible bricks and text-labelled coupons. bikar is the DSL and geometry engine, qiyas the CV validator, 3d-models the publishing end, sacred-patterns the canonical contract — see [[orb-repo-roles]].

**Where things live:** open work is the task system mirrored by `docs/plan.md`; the dated ship log (PR + sha per merge, 2026-07-23 → 2026-09-02) is archived verbatim in `docs/research/shipped-record.md`; new ships go to plan §3, never to memory. Durable text cites stable ids (D-number, CAL-*, PR + sha), never task numbers.
