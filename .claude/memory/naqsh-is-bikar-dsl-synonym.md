"naqsh" is the name of the language; "bikar" is the engine, the repo, the CLI and the
`@naqshcoffee/*` packages. When Omar says "create a new naqsh file", write a `.bkr` file. No
package, directory or extension renames.

**Why:** Omar, 2026-09-16, when offered a rename scope for the GeoGebra-import work: "actually
lets keep bikar name, lets naqsh be a synonym ... if i say i want to create a new naqsh file we
should make .bkr". A full rename touches ~357 `.bkr` files and every gate for zero product
value.

**How to apply:** write docs as "naqsh (the language) — bikar (the engine)". Never propose a
rename again. Related: [[islamic-orb-project]], [[orb-repo-roles]].
