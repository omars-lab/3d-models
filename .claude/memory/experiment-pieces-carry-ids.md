Omar 2026-10-27, after split-10 printed: "why did we print an experiment plate where each piece isn't identifiable / has id?" split-10's 30 pieces all carried `no_id` with the reason "an id goes only on a hidden face (D-114)", relying on bed position, which is lost the moment the pieces come off. D-115 already said a coupon's upper half carries its id on the outer face; D-114 is for coasters that are sold.

**Why:** a fit experiment (kite gaps 0.12/0.10/0.08, dovetail 0.15/0.10/0.05) is worthless if the copies can't be told apart in the hand.

**How to apply:** on any experiment plate, never reuse a D-114 no-id reason. Give every piece an id (outer face per D-115, or the cut face when the outer face is what is judged, e.g. a star's flatness), or a physical tell written on the page.
